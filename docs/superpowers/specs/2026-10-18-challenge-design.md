# 挑战模式：十二关几何与场景玩法

日期：2026-10-18。状态：设计待确认，尚未实现。

## 目标与范围

以十二个模型与互动场景替换原挑战模式的限时立方体。取消倒计时、消除补时间和超时失败。沿用现有纯 HTML/CSS/JavaScript/WebGL 项目，不新增运行依赖。普通模式与独立测试关保持现有规则。

用户明确要求：几何体可使用正方体、斜块、三角体等小块构成，不必强行体素化；开场掉落和消除后的逐面掉落原则与普通关卡一致；所有挑战关均可使用视角模式。第四关三个堵塞集合体各自约为 7×7 正方体的尺度。

## 共同规则

- 至少两个同色相接小块可以点击整组消除，得分沿用 5×块数²；实体只计数一次。
- 每关支持完整相机旋转、缩放、提示，以及可见边缘相接的视角配对。完全遮挡、仅角接触、明显间隙不算。视角配对只改变消除连接，不改变水路、碰撞、承重或弹珠物理状态。
- 开场小块从上方落到模型槽位。消除后在所属面内沿箭头方向下落收拢，不补充新块。侧面向下，水平顶底面朝模型前方；斜面采用世界向下在面内的投影。曲面以固定表面条带定义连续落块轨道，极点使用稳定的预定方向。旋转相机不改变重力。
- 分块必须对应真实可见几何、拾取和接触判定。不能只用外观遮罩把立方体伪装成别的形状。不同轮廓槽位用槽位形状显示迁入的颜色，颜色/实体迁移不产生重复计分。
- 各面标示掉落方向；运动机关暂停时才允许其小块参与点击消除，暂停游戏时所有机关与物理模拟冻结。

| 2 | 圆柱。圆周使用扇形/弧面块，端面也可消除。 | 同上。 |
| 3 | 球体。使用球面分块，包含极区，不用立方体外壳代替。 | 同上。 |
| 4 | 水箱下端连接透明管道，通到火堆旁的出水口；沿途有贴满内壁的塞体、上下移动的板子、贯穿管壁的集合体。消除前两者打开通路，第三者需要保留管壁封口部分以免漏水。每个集合体约为普通 7×7 主体大小，镜头能覆盖整体并放大局部。 | 连通水路且出口持续出水，灭火进度达到 100%。 |
| 5 | 三棱柱，包括两端三角面和三个长侧面。 | 无可消组合后按分数结算。 |

| 9 | 两个由可消除小块组成的齿轮，按转动—停靠周期同步反向转动，每次停靠齿与槽刚好啮合。停靠接触处的同色块可以跨齿轮消除。 | 无当前或未来停靠可消组合后按分数结算。 |
| 10 | 两个有缺口的环形靶；待投方块总数等于两靶缺口总数，颜色随机。瞄准显示白色抛物线和落点，发射可补缺口，也可打中现有靶环，环数×10加分。投射结束后开始普通消除。 | 消除阶段无可消组合后按分数结算。 |
| 11 | 跷跷板两端各放由三个几何体组成的集合体，初始平衡。消除改变两边重量和板高；可沿板移动集合体，利用两边相容部位贴合形成消除机会。两端透明挡板防止滑落。 | 无当前或可操作到达的消除组合后按分数结算。 |
| 12 | 弹珠机式场景，通过消除小块挖出通道，让弹珠落到底部指定分数框。 | 弹珠进入目标框，按该框分数奖励并通关。 |

## 用户已补充的第八关规则

拼接阶段看不到颜色，使用中性材质；完成拼接后才随机分配颜色，并继续消除玩家自己拼出的组合体。完成前不预先生成或透露颜色。完成后锁定拼接布局，不允许返回拼接阶段重抽颜色。

## 建议默认值（由实现方提出，待随整体设计确认）

1. 第八关允许使用零件框中的部分几何体，至少使用两个，组成一个通过实体接触连通且不穿透的组合。提供撤销、移除和重置；鼠标/触屏用独立编辑控件避免与旋转视角冲突。「完成拼接」位于下方零件框右侧。选择面后吸附，并支持绕接触面旋转。
2. 第九关“由”之后未写完，默认由可消除的彩色齿块及轮体分块组成。两轮同时反向转动，再同时停住；复用现有 2.4 秒停靠、0.8 秒转动节奏，每次一个齿距。消除不改变齿轮中心和运动周期；缺齿真实保留为空洞。
3. 第四关采用可预测的离散水路模拟。水通过当前空隙连通到出口才推动灭火；漏口连通到水箱后优先泄水并停止有效灭火。漏水时明确高亮损坏位置，允许重试，不假装成功。水箱默认无限供水，没有隐藏倒计时；持续有效出水约 3 秒灭火。封口块是可消除块，外观用边框提示其密封作用。默认封口块固定槽位，内部堵塞块在各自有限轨道收拢，避免重力自动把封口移走；这是场景约束对逐面掉落的必要限制。
4. 第十关默认每靶 5 环，外环到内环记 1—5 环；补缺口只补块，不额外记靶环分；击中完整靶环得环分，投射块吸附于命中面且加入后续消除。未命中也消耗一块。发射前允许任意调整瞄准；轨迹、落点和实际首个碰撞共用同一求交逻辑。
5. 第十一关按存活块体积计算重量，支点两边力矩决定倾斜；各端初始总力矩相等。倾角受限，集合体不穿过支点或挡板；平移控件和相容接触面用于辅助贴合。不因一次静止状态没组合就过早结束；提供「结束本关」供玩家确认结算剩余分数。
6. 第十二关默认先消除布置，再点击「释放弹珠」，一颗球；释放后仍可消除，底部设 100/300/500/300/100 分框，中央 500 分框为目标。落入其他框算失败并可重试。弹珠与实时剩余块碰撞，不穿透、不按预设动画直接到目标。
7. 用户已明确：挑战模式每关独立计分，任何选关、重玩或继续下一关均从 0 分开始。通关只看本关分数，目标须按本关实际块数和玩法标定，不能依赖前面关卡的累计得分。保留本关剩余块奖励。第四、十二关的场景完成条件仍需满足。
8. 新挑战模式使用独立版本的进度存储，避免旧计时赛成绩直接解锁新关。保留旧数据和普通模式记录；新模式第一关解锁，第十二关后显示全部通关，支持已通关关卡重玩。

## 实现边界与结构

保留原 Board 作为普通/测试模式实现，为挑战模式增加形状槽位、真实面片、接触图、表面重力轨道与组合体变换。渲染与拾取扩展到凸多面体及弧面离散网格；视角连接复用当前可见接缝原则，使用真实投影边界和遮挡检查。

关卡控制器区分入场、编辑、瞄准/投射、消除、模拟、结算状态。应用负责模式菜单、HUD、进度和得分；场景控制器负责水路、齿轮、跷跷板和弹珠，不能把这些效果只做成动画。提示、无解判定和结算必须理解阶段与机关未来可达状态。

模型整体尺度默认接近现有主体，分块密度以 7 格尺度为基准；复杂场景自动取景，不把三个 7×7 集合体压成一个 7×7 主体。透明管道和挡板可视但不抢占后方可消块的点击。

## 验收

- 挑战选关恰好十二关，名称/模型/说明正确，无任何倒计时失败与补时行为。
- 每关支持转动、缩放、视角配对、提示、暂停和重试；暂停不推进机关。
- 六种单体模型、双环与齿轮有真实轮廓，匹配/拾取/阴影与可见形状一致。
- 入场、逐面收拢、唯一计数、跨组件接触与遮挡判定都有可重复测试；随机种子可用于回归。
- 第八关完成前无颜色信息；完成后分配颜色并保留玩家布局。
- 第四关验证疏通成功、移动板开闭、封口破损漏水、灭火完成；第十关验证补洞、环分、未命中和投射后消除。
- 第十一关验证初始平衡、力矩变化、限位和接触消除；第十二关验证碰撞、通路变化、不同分数框及失败重试。
- 回归现有 Node 测试，并进行桌面和窄屏浏览器实际操作验证。不得把仅有静态模型的版本称为十二关完成。
