# 消灭星星 3D

**在线试玩：<https://star-njjh.onrender.com/>**

普通模式把《消灭星星》搬到立方体六个面；挑战模式提供十二个几何与场景关卡，包括高楼营救、魔方消除、齿轮、弹弓补靶、跷跷板和弹珠通道。

## 怎么玩

双击 `index.html` 即可。纯 HTML + WebGL 实现，没有任何依赖，不需要联网、不需要构建。

（如果浏览器因为安全策略不让本地页面加载脚本，就在这个目录下起个静态服务：
`npx serve .` 或者 `python -m http.server`，然后打开提示的地址。）

操作：

- 拖动 —— 上下左右完整旋转视角，可以转过顶面和底面
- 左下角竖杆 —— 圆点初始在底部，向上拖动逐渐放大；准星按钮将当前面转正到箭头朝下，保留缩放
- 滚轮 / 双指 —— 缩放，并同步更新竖杆位置。所有关卡共用最大放大限制：主体保留少量页面边距，旋转或调整窗口后自动校正；有底部操作栏时，主体不会被操作栏挡住。
- 每面白色小箭头 —— 指示该面的方块掉落方向
- 右下角「提示」—— 标出一组可消除方块，白色覆盖并轻轻弹跳；优先选择可见组合，必要时转向背面组合，不扣分
- 点击 —— 消除连在一起的同色方块（至少 2 块）
- 鼠标悬停在可消的组上 —— 会显示「n 块 · +多少分」，省得自己算
- `Esc` —— 暂停

最高分会自动存在浏览器里，下次打开还在。挑战选关按钮显示每关「历史最高分」，只记录成功通关的最高成绩，低分重过不会覆盖旧纪录；每次挑战仍从 0 分开始。左上角「返回选关」可随时回到当前模式的选关页，说明弹窗右上方「返回」可关闭说明。

## 规则

普通模式的视角拼接关，以及挑战模式全部十二关支持视角配对：转动视角，让不同位置的同色方块在画面中形成可见接边，再点击整组消除。完全遮挡、只碰角和明显间隙不算连接，同一实体只计一次。挑战模式视角拼接始终开启。入关自动显示说明弹窗，点击「我知道了」关闭，通过「！」可再次查看；拼接、投射等操作仅在需要时显示。普通模式的经典关、旋转方板关仍仅按实体接触判断。

普通与挑战模式先进入选关页，各自保存通关记录。普通模式第 1 关默认解锁，通关后解锁下一关；挑战模式第 1—12 关暂时全部开放供测试。彩色按钮标明“可挑战”或“已通关”，均可直接点击进入。普通模式尚未解锁的按钮为灰色并显示 🔒。“开始／继续闯关”也可进入当前可挑战关卡。普通模式重玩恢复首次通关时的入关分数，继续闯关保留前一关结算分；挑战模式每关始终从 0 分开始。记录保存在当前浏览器；旧版没有逐关记录，更新后开始累计，测试关不写入通关记录。

- 点一下**连在一起的同色方块**（至少 2 块）就能消掉，得分 `5 × 块数²`。方块越大越赚。
- 连在一起 = 贴着的一格之内。**同一面上下左右相邻，或者翻过立方体棱边的相邻**都算。
- 消完之后每一面沿自己那一面的「下方」收拢：四个**侧面向下滑**，**顶面和底面朝前面滑**。
  所以整块立方体会慢慢往下沉、往前堆。
- 六个面都找不出相邻同色时本关结束，按**剩余方块数**结算清空奖励。
- 普通模式累计分数达到**目标分**才能进下一关；挑战模式每关独立计分，本关分数达到本关目标即可。

挑战模式十二关全部开放，无倒计时。选关、下一关、重试均从 0 分开始，按本关块数和场景要求独立设定目标。新关卡通关记录使用独立版本，旧计时赛分数不会带入。消除关可点击「结算本关」检查目标；高楼营救和弹珠关须完成各自的场景任务。

## 两种模式

| 模式 | 关卡 | 特点 |
| --- | --- | --- |
| 普通模式 | 5×5 至 9×9，共 15 关 | 每个尺寸依次安排普通消除、旋转方板、视角拼接 |
| 挑战模式 | 十二个几何与场景关 | 不限时、每关独立计分、全部开放、每关可视角拼接 |

### 挑战模式十二关

| 关 | 内容 | 操作与目标 |
| --- | --- | --- |
| 1 | 三棱锥 | 保留完整平整的三棱锥外形，沿斜面分层划出四边形色块，仅尖顶保留必要的三角形 |
| 2 | 圆柱体 | 小正方体拼成圆柱，顶底使用方格，边界无重叠薄片 |
| 3 | 球体 | 圆润球面划成均匀四边形色块，避免细条与独立三角碎块；色块为有厚度的实体 |
| 4 | 高楼营救 | 六层楼，每层8×9，上面两层为独立小方块，下面为完整单色承重板。四角柱正面3×4、厚3格，部分灰柱不可消除。单角或对角失去支撑保持水平，同侧两角失去支撑则倾斜，残柱承接楼板；柱子全失后楼板落到下层。承重板消除后，上方方块和人物立即下落。逐层营救安全落地奖励500分，过高落差或被坍塌楼板砸中失败；分数达标不能跳过营救任务 |
| 5 | 三棱柱 | 三角端面与三个侧面均可消除 |
| 6 | 棱台 | 四边形实体块随斜面逐层收窄，保持完整外形，去除细扁色条 |
| 7 | 十字双环 | 两个同样大小的实心扁平环带垂直交叉，交点贴合且不重叠；环面以四边形块组成，保留中央环孔 |
| 8 | 魔方消除 | 三阶魔方，每面九个大格，每个大格包含5×5随机色小正方体。白色边缘箭头控制整行、整列90度旋转，深色凹槽区分大格；六面均有掉落箭头。单个小方块可跨凹槽向下补位，止于当前面边缘 |
| 9 | 啮合齿轮 | 两轮反向一转一停，停靠啮合时可跨轮消除 |
| 10 | 投射补靶 | 独立于第4关。左右靶各5个缺口，共10发弹药。拖住弹弓方块向后拉，距离决定拉力、方向决定反向弹道，松手发射；暂停、取消和轻点不耗弹。预览与实际抛物线一致，命中已附着方块的侧面也能正确贴合，投完进入消除 |
| 11 | 平衡跷跷板 | 正面水平视角起始，只能左右、上下平移及缩放。两端各三个几何体；消除改变重量并使板面倾斜，挡板限位；保留左右块数和倍率提示，无底部移动按钮 |
| 12 | 弹珠通道 | 尖头朝上的三角障碍由两个有清晰拼缝的同色块组成；按住发射器左右拖动调整±50°角度，白色箭头预览首次碰撞位置，固定力度，点击按钮发射。共三次发射，碰撞每次加100分；五个槽从左到右加100、300、500、300、100分，发射后仍可消除 |

挑战模式点击「提示」会将可消除的组合居中放大，以白光和轻微跳动标出；消除后恢复原缩放。连续点击提示不会丢失高亮，跷跷板提示保持水平视角。

除跷跷板仅允许平移视角外，场景可旋转和缩放，暂停冻结机关及弹珠。几何体以有厚度的实体块填满轮廓，三棱锥、球体、棱台和双环的主要表面采用四边形色块。挑战配对要求一段可见接边，仅碰顶点或依靠隐藏内部接触面不能串连。魔方转动时暂停消除，停稳后逐面下落，深色主体会挡住背面方块的选择。高楼构件按重力与实体碰撞下降，弹珠障碍固定。

### 普通模式

第 1 关为普通 5×5 消除，不使用黑色问号膜；
第 2 关为 2×3 旋转方板，停 2.4 秒后用 0.8 秒转 90°。方板贴在主体面上，正对该面看按上、右、下、左顺时针依次停靠，停靠时外沿与主体边缘齐平。转弯时略向内收，完整旋转过程不超出该面范围；实际接触的同色组合可点击消除。
第 3 关为固定 2×3 视角拼接板，放在主体旁边。转动视角，使实际可见面的边缘对齐相接，即可点击同色组合消除；只露出部分但接边可见的方块也算。主体遮住方板一部分后形成的可见接缝同样有效，判定直接检查接缝两侧显示的方块。完全遮住、只碰角或有明显空隙不算连接。方板自身不会移动，也不会自动消除，同一实体的多个可见面只计一块。
普通模式不使用内部通道、挡板和灰色问号块。

菜单中的「关卡测试」区域已移除。

普通模式各尺寸的机关板数量依次为：5×5 一块、6×6 两块、7×7 三块、8×8 四块、9×9 五块。旋转板前四块在同一面按上、右、下、左排列，保持相位一起顺时针轮换；多板转动过程中角部可短暂越过面边缘，停靠时逐格对齐且互不穿透。9×9 第五块在周围四个侧面间绕行，停靠后与对应面实际接触。视角板分别固定在不同面外侧。独立测试关的方板数量保持原配置。

普通模式：1—3 关 5×5，4—6 关 6×6，7—9 关 7×7，10—12 关 8×8，13—15 关 9×9。每组三关依次为普通消除、旋转方板、视角拼接。第 15 关通过后显示全部通关，可返回选关重玩。普通模式目标分按当前格子数量和关卡计算。

普通模式棋盘为小正方体搭成的空心外壳。没有可消除组合时，剩余孤块依次炸开并绽放彩色烟花，
烟花结束后显示结算；这部分特效不会增加消除得分，剩余块数仍按爆炸前统计。

方块共六色：红、紫、绿、蓝、黄、粉。

## 设计说明

传统玩法搬到立方体上，有几处需要定规矩的地方，这里是本版本的取舍：

- **跨棱边算相邻**：立方体表面是连通的，翻过棱边的同色方块能一起消，
  这是这个版本和「六个独立平面」最大的区别，也更容易凑出大团。
- **逐面重力**：每面有自己的「下方」。四个侧面的下方就是世界坐标的下方；
  顶面和底面是水平面，没有天然的下方，取「朝观察者的前方」，这样六面规则统一、
  玩家也容易预期。
- **关卡目标**：传统公式是按 10×10 棋盘标的，6 色下每关产出比 5 色低不少，
  所以目标分改成 `(750×关数 + 350×关数×(关数-1)) × 格子数/150` 后取整，
  是按真实对局模拟标定的。清空奖励同理改成了按剩余占比计算（传统公式 `2000-20r²`
  在 6 色下恒为 0，因为一局结束平均还会剩三分之一的孤块）。
- **小正方体外壳**：每个方块长宽高相等，紧密拼成空心六面体，没有黑色内核。
  棱边和角上的方块由相邻面共用，只计数和消除一次；N 格外壳共有 `N³-(N-2)³` 块。
  下落按所属面分区进行：顶底包含水平棱和角，前后包含竖棱，左右为剩余区域。
  消除后可透过空洞点击里面可见的方块。

## 验证

安装 Node.js 后运行 `node --test`，覆盖普通模式、真实多面体拾取、表面重力、齿轮全周期无穿透、视角接缝、十二关状态及场景规则。

Windows 安装 Microsoft Edge 后可运行 `node scripts/verify-challenge.cjs`，启动隐藏的本地浏览器，逐关截图并验证真实点击、魔方转动、弹弓补洞、高楼营救及摔伤/砸伤、弹珠发射方向、跷跷板平移、全程缩放、暂停、重试及手机布局；截图保存在忽略提交的 `.qa/`。
